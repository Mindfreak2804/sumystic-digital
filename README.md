# Sumystic Digital

Performance marketing agency website for **Sumystic Digital** — e-commerce, pay per call, CPS, peptides, and full-funnel paid media.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```
